# VPS 域名绑定与服务端请求恢复

## 设计

- Remote 的 domain_zones 保存允许的后缀，domain_zone 保留为主后缀和旧配置兼容字段。Mapping 的 domain_zone 固定本隧道选择。
- 服务端通过私有 SSH 控制接口维护 zones.json，校验主后缀属于允许列表；不允许删除仍有注册域名的后缀。新增后缀的 DNS、Nginx、证书仍须真实配置。
- 客户端按 VPS 管理后缀，可读取服务端最新配置；新隧道默认主后缀、下拉切换；修改主后缀不改变旧隧道域名。旧单后缀与全局配置兼容。
- 服务端复用现有客户端每15秒的 SSH 上报通道返回定向恢复指令，不开放新的公网控制端口，也不发送任意 shell 命令。
- 服务端检测入口端口异常或客户端上报失败后排队；恢复请求有唯一ID、冷却与过期。客户端按本地启停意图、有效期、作废状态和服务端禁用策略复核，仅恢复本 VPS 所属隧道，回传执行结果。
- UI 提供后缀管理、后缀选择、请求恢复、恢复状态与结果；认证及CSRF保持。

## 验收

- 多后缀可保存重启、切换主后缀、选择副后缀，跨VPS和非法后缀拒绝；旧域名和配置兼容。
- 模拟丢失入口后恢复命令经上报返回并执行，健康隧道不反复重启；停止、过期、禁用、作废和错误owner不拉起。
- go test ./...；go test -race ./internal/manager ./internal/relay ./internal/serverui；前端语法与浏览器交互检查。
- 发布两个VPS后发布三个客户端，保留配置与二进制备份；五入口身份与登录、映射健康、服务自启复查；不发布Money。
