# 离线隧道手动唤醒修复

根因：页面根据 invalid / desired_running 禁用恢复按钮，服务端手动请求又复用了自动恢复资格，客户端再次拒绝作废和停止状态。正常在线隧道可操作，真正断线熔断后却无法唤醒。

手动唤醒是经登录和CSRF验证的显式启动指令，与自动恢复分开。可启动停止和连接失败作废的隧道，重置失败次数；自动恢复仍不擅自启动停止/作废隧道。服务端禁用、有效期届满仍需先启用或续期。

客户端控制通道离线时保存待执行请求，连接后再给指令一分钟执行期限；待执行请求持久化。协议能力显式上报，旧客户端显示“等待客户端升级”，不得把已排队当执行成功。

验收：离线、停止、作废按钮可点击；过期和禁用给明确原因；服务端排队、客户端恢复、回执和入口探测闭环；覆盖旧版本、跨客户端隔离、重复指令和服务端重启。
